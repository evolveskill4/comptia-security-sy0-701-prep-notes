## 🎯 Exam Specification
- **Exam Code:** SY0-701
- **Focus:** General Security Concepts, Threats/Vulnerabilities/Mitigations, Security Architecture, Operations, and Governance.
- **Passing Standard:** 750 (scaled score 100–900)

---

## 📌 Domain Weighting & Core Focus

### 1. General Security Concepts (12%)
- Practical application of Security Controls (Technical, Managerial, Operational, Physical).
- Fundamental CIA Triad implementations and data sensitivity classification.
- Core tenets of Zero Trust Architecture (ZTA): verify explicitly, least privilege, assume breach.

### 2. Threats, Vulnerabilities, and Mitigations (22%)
- Threat actor capabilities, taxonomy, and attack vector surfaces.
- Analyzing common indicators of compromise (IoC) and software security weaknesses.
- Cryptographic vulnerabilities, TLS downgrade risks, and baseline mitigation hardening.

### 3. Security Architecture (18%)
- Cloud deployment models (IaaS, PaaS, SaaS) and shared responsibility matrix.
- Network segmentation, zero-trust network access (ZTNA), and secure enclave design.
- Business continuity, fault tolerance, and disaster recovery strategies.

### 4. Security Operations (28%)
- Centralized event logging, SIEM dashboard analysis, and SOAR automation triggers.
- Incident response procedures, digital forensics preservation, and evidence chain-of-custody.
- Identity and Access Management (IAM), multi-factor authentication (MFA), and federated trust.

### 5. Security Program Management & Oversight (20%)
- Risk assessment methodology, qualitative vs. quantitative analysis, and risk register management.
- Compliance frameworks (NIST CSF, ISO/IEC 27001) and global data privacy standards.
